About Me

My Journey

I'm a Senior Software Engineer at Wells Fargo in Hyderabad. For the last four years I've worked on the systems our capital markets trading desks use for pricing, risk, reference data and reporting. Most of it is backend work: Java and Spring Boot services that talk over Kafka, cache in Redis and run on Kubernetes.

Making trading systems faster is the kind of problem I enjoy most. I care about clean service boundaries, solid CI/CD and dashboards that show problems before traders notice them.

Lately I've been building AI-powered developer workflows. The most recent is a set of agents that writes Spring Boot integration tests, now used across more than 80 of our microservices.
